# UI/UX Guidelines

Apply the comprehensive UI/UX guidelines from `docs/ui-guidelines.md` to all frontend work.

## Instructions

1. Read the guidelines from `docs/ui-guidelines.md`
2. Keep these principles in mind throughout the session
3. Proactively apply guidelines when:
   - Creating new Blade views or components
   - Modifying existing UI elements
   - Working with forms, inputs, buttons
   - Implementing animations or interactions
   - Adding responsive/mobile features
   - Reviewing accessibility

## Key Areas Covered

- **Interactivity**: Forms, inputs, buttons, hover states, focus management
- **Typography**: Font rendering, weights, sizing, readability
- **Motion**: Animations, transitions, performance considerations
- **Touch**: Mobile-specific behaviors and optimizations
- **Optimizations**: Performance best practices for CSS and animations
- **Accessibility**: Screen readers, keyboard navigation, ARIA labels
- **Design**: Feedback patterns, empty states, optimistic updates

## Usage

When making UI decisions, reference specific guidelines from the document and explain how you're applying them.
